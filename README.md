# 地理探测器分析与制图平台

基于 **R plumber（计算后端）+ ECharts（前端制图）** 的本地网站。计算与绘图彻底分离：
GD 包负责地理探测计算，所有图表在浏览器中重写渲染——改样式即时生效、无需重算，并可高分辨率导出。

整套程序在本机运行，数据不出本地、无需联网。一次性配置好 R 环境后，双击即可使用。

---

## 一、运行环境与依赖

### 1. R 环境

- 需要 **R 4.x**（开发与测试基于 **R 4.5.2**，Windows x64）。
- 安装后请记下 `Rscript.exe` 的完整路径，例如：
  `D:\Program Files\R\R-4.5.2\bin\Rscript.exe`

### 2. R 依赖包（首次使用前安装一次）

后端运行需要以下 7 个包：

| 包 | 用途 |
|---|---|
| `plumber` | 提供 REST API 与静态网页服务 |
| `GD` | 地理探测器核心算法（最优离散化 + 因子/交互/生态/风险探测） |
| `readxl` | 读取 `.xlsx / .xls` 上传文件 |
| `jsonlite` | 前后端 JSON 数据交换 |
| `car` | 共线性检测（VIF / 容忍度） |
| `later` | 心跳看门狗（关闭浏览器后自动停止后端） |
| `callr` | 在独立子进程中执行计算，支持「随时停止」 |

在 R 控制台或命令行一键安装：

```r
install.packages(c("plumber", "GD", "readxl", "jsonlite", "car", "later", "callr"))
```

命令行方式（替换为你自己的 R 路径）：

```bat
"D:\Program Files\R\R-4.5.2\bin\R.exe" -e "install.packages(c('plumber','GD','readxl','jsonlite','car','later','callr'))"
```

> 这些包均从 CRAN 安装。`GD` 的依赖较多，首次安装可能需要几分钟。

### 3. 浏览器

需要 **Chrome / Edge** 等现代浏览器（程序会自动调用默认浏览器打开页面）。

### 4. 前端库

ECharts、JSZip、SheetJS 等前端库已全部本地化打包在 `www/lib/` 中，**完全离线可用，无需 npm / 构建步骤**。

## 二、启动方式

### 方式一：双击启动（推荐）

1. 用文本编辑器打开 **`启动网站.bat`**，确认顶部一行的 R 路径与你机器一致：

   ```bat
   set "RSCRIPT=D:\Program Files\R\R-4.5.2\bin\Rscript.exe"
   ```

   如不一致，改成你自己的 `Rscript.exe` 路径并保存。

2. **双击 `启动网站.bat`**。它会：自动检测端口 → 启动后端服务 → 等待就绪 → 打开浏览器。

3. 浏览器自动访问 <http://127.0.0.1:8765/index.html> 即进入平台。

### 方式二：命令行启动

```bat
"D:\Program Files\R\R-4.5.2\bin\Rscript.exe" run_app.R
```

启动后在浏览器手动访问 <http://127.0.0.1:8765/index.html>。

### 如何停止服务

- 关闭名为 **"GD-Server"** 的 R 命令行窗口；**或**
- **直接关闭浏览器页面**——前端心跳停止约 90 秒后，后端会自动退出（兼容后台标签页节流，不会误关）。

> 前端资源带 `no-store` 响应头，服务每次启动会自动刷新前端资源链接；改动代码后**重启服务并刷新页面**即生效。

### 双击 bat 后没反应？

bat 启动器使用英文提示以避免 Windows 代码页问题。常见情况：

1. **浏览器显示"无法访问此网站"** — R 包首次冷启动可能要 15~30 秒，刷新一次即可（bat 已自动轮询端口最长 60 秒）。
2. **GD-Server 窗口一闪而过** — 通常是 R 包没装齐，按上文第 2 节重新安装依赖。
3. **bat 报 `Rscript not found`** — 修改 bat 顶部 `RSCRIPT=` 行，指向你机器上 `Rscript.exe` 的真实路径。
4. **端口 8765 被占用** — bat 会自动结束旧服务并以最新代码重启；如仍异常，手动结束所有 `Rscript.exe` 进程后重试。

## 三、使用流程（按页面顺序）

| 页面 | 功能 |
|---|---|
| ① 数据上传 | CSV / Excel 多文件上传（自动识别 UTF-8 / GBK 编码，`<空>` 自动转 NA）；**面板数据自动解析模块**：自动分离动态变量（带年份🔄）/ 静态变量（常量📌），过滤 OBJECTID/Shape/ORIG_FID/FID/Id 等字段——① 年份按钮多选（默认全选）② Y 下拉单选 ③ X 标签按点击顺序命名 x1,x2…，点「连续/分类」标签切换类型；**「拆分为年度数据集」**后只显示 `y/x1…xn`，常量列复制到每年。删除原始表会级联清除其拆分/统计/探测结果，另有「清空全部缓存」一键重置 |
| ② 统计检验 | 描述统计与**方差检测**（零方差预警）、**共线性检测**（VIF + 容忍度，≥5 / ≥10 分级预警）、**相关性分析**（Pearson / Spearman + 显著性），自动汇总预警 |
| ③ 地理探测 | OPGD 参数（5 种离散化方法 × 自定义分级数范围）、Y=0 剔除、超量随机抽样、**离散化寻优抽样**（默认启用、上限 5 万，可取消改用全量数据）；**单数据集 / 批量运行**，独立子进程 + 实时进度 + **可随时停止** |
| ④ 制图中心 | 6 类图表 + Origin 式样式控制台（每图数十项可调，见下） |
| ⑤ 结果导出 | **一键导出全部结果**（4 类可选、默认全选）：①按年份整理的训练数据 CSV ②全部图片 ③`数理统计结果.xlsx` ④`地理探测器结果.xlsx`；后两者按结果类型分多个工作表、纵向堆叠所有年份。也可逐表预览并单独导出 CSV |

### 数据上传与拆分流程（ArcGIS 宽表 → 年度训练集）

针对从 ArcGIS 导出的宽表（一张表含多年，列名带年份如 `2000_CES` / `CES2022`，并带 OBJECTID/Shape 等字段）：

1. 上传原始表，**预览**区展示完整原始表。
2. **面板数据自动解析模块**只显示去重后的变量基名（年份已剥离、ID/几何字段已过滤）：年份按钮选择要提取的年份，Y 下拉选因变量，X 标签按点击顺序选自变量（命名 x1,x2…，再点可切换为分类 X）。
3. 点击**「拆分为年度数据集」**：为每个选中年份生成一个 `y, x1…xn` 训练表；没有年份后缀的**静态常量列**（如高程 dem）复制进每一年。
4. 拆分后的数据集进入统计检验、地理探测、制图、导出流程。

## 四、制图中心（全部为重写实现，不依赖 GD 包原生图）

1. **因子探测**：柱状/条形、排序、q 值渐变着色、显著性星号、可编辑注释行
2. **交互探测热图**：上/下三角 + 对角线布局、q 值标签、双因子增强 `*` / 非线性增强 `**` 标记、自绘无缝色标、X/Y 轴翻转、X 轴变量名旋转、对角线旁变量标注
3. **离散化寻优**：每个连续变量一个子图，展示 *每种方法 × 每个分级数* 的 q 值全过程曲线，标记最优点——完整呈现 OPGD 参数寻优过程
4. **生态探测**：三角显著性矩阵（Y/N 双色）
5. **风险探测**：分面柱状图（每变量一个面板，分区 Y 均值 + 数值标签）
6. **相关性热图**：Pearson / Spearman、下三角可选、显著性星号、自绘无缝色标

**样式控制台**（所有图初始即按因子数量自适应，之后任意修改）：

- **全局设置**：字体（默认中文宋体 + 英文新罗马混排）、导出格式（PNG / JPG / SVG 矢量）、**导出分辨率 DPI（默认 600）**。
- **每图独立的完整样式集**（分组折叠）：标题、坐标轴（轴线/刻度/网格/标签/旋转/范围，每条轴独立设置）、数值标签、图例与色标、配色（多套 SCI 色带 + ★自定义色带编辑器，可加减颜色节点、反转）、逐边框开关、画布宽高、绘图区边距。
- 图表专属智能项：交互热图**智能色标定位**（自动放入空白三角区，也可右侧/底部/手动定位 + 偏移微调）、对角线旁标注、X/Y 翻转；离散化寻优图空心/实心数据点、最优点符号、子图行列距、标注智能避让。
- **变量显示名映射**（x1 → 实际因子名，仅影响显示）。样式自动保存（localStorage）。

**导出**：当前图（按全局格式 / DPI 设置）；一键批量导出全部文件 × 全部图表 ZIP。

**停止功能**：地理探测计算在独立 R 子进程（callr）中执行，前端轮询进度并显示已用时；数据量过大时点击「停止」即杀掉子进程立即终止，已完成文件的结果保留，主服务不受影响。

## 五、数据格式要求

- **方式一（推荐）ArcGIS 宽表**：一张表含多年，列名带年份（`2000_CES`、`CES2022` 均可），可含 OBJECTID/Shape/ORIG_FID 等字段；上传后选 Y/X，点「拆分为年度数据集」自动整理。
- **方式二 已整理表**：直接是 `y, x1, x2 …` 列（无年份）；上传后选好角色，拆分会生成单个数据集。
- 因变量列为 `y`，自变量列为 `x1, x2 … xn`；空值可用 `<空>` 表示，含缺失的行自动剔除。

## 六、项目结构

```
geodetector-web/
├── run_app.R          # 启动脚本（plumber，端口 8765）
├── 启动网站.bat        # 双击启动（内含 Rscript 路径，可按需修改）
├── api/
│   ├── plumber.R      # API 路由（上传/统计/拆分/可中断探测任务/取数）
│   └── core.R         # 核心计算：读取/清洗/统计检验/optidisc + gd + gdinteract + gdeco + gdrisk
├── www/               # 前端（纯静态，无需构建）
│   ├── index.html
│   ├── css/style.css
│   ├── js/charts.js   # 制图引擎：6 类图表的自适应默认值 / 样式 schema / ECharts 构建
│   ├── js/app.js      # 页面逻辑、上传拆分、API 调用、导出中心
│   └── lib/           # echarts / jszip / xlsx(SheetJS)（已本地化，离线可用）
```

后端 API：`/api/upload` 解析上传、`/api/split` 按列拆分年度数据集、`/api/stats` 统计检验、
`/api/run_start` + `/api/run_poll` + `/api/run_stop` 可中断的探测任务、`/api/get_csv` 取回训练数据。

## 七、常见问题

- **计算很久没结果？** 大样本下 natural(Jenks) 等离散化寻优非常耗时。③ 地理探测页默认**启用抽样加速**（上限 5 万）：先抽样找最优分级断点，再把断点应用到全量数据算 q 值，速度快很多且 q 值几乎不变。需要最高精度时可取消勾选，改用全部样本（会明显变慢）。
- **改了代码不生效？** 重启服务（关闭 GD-Server 窗口后再次双击 bat），并在页面按 Ctrl+F5 刷新。
- **图不好看？** 到 ④ 制图中心右侧样式控制台逐项调整，或点「恢复自适应默认样式」。
